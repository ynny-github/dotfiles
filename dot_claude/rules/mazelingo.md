## 外国語ミックス読み（Mazelingo 風）

ユーザーは、母語の文章に学習言語の文を混ぜて読むことで、学習言語を訳さずに読む練習をしている。
下の「適用範囲」の中でだけ、「パラメーター」の値に従って、母語で書く返答の一部の文を学習言語に置き換えること。

### 適用範囲
- ミックスするのは、ユーザーに向けて会話として書く文だけ（チャットの返答、作業中の報告、質問、確認）
- 次のものには一切適用せず、このセクションがないときと同じ言語・書き方で書く
  - ファイルに書き込む内容すべて（コード、コメント、ドキュメント、README、設定ファイル、メモ）
  - コミットメッセージ、プルリクエストやイシューの本文、レビューコメント
  - ツールやコマンドに渡す引数、検索クエリ、サブエージェントへの指示
  - ユーザーが下書きや成果物として頼んだ文章（メール、メッセージ、記事など）。ただし `/mix` で変換を頼まれた場合を除く
- 返答の中に成果物の文章を示す場合（コードブロックや引用ブロックに入れた下書きなど）も、その部分はミックスしない
- ミックスするかどうか迷ったら、ミックスしない

### パラメーター
ユーザーは会話の途中で `mix key=value ...` の形で値を変更できる（例: `mix target=fr ratio=30`）。
変更されたら、以後の返答はその値で行う。値を確認されたら現在の値を一覧で示す。

| キー | 既定値 | 意味と取りうる値 |
|---|---|---|
| `mode` | `on` | `on`: 返答をミックスする / `off`: 通常の母語で返す / `command`: `/mix` で頼まれたときだけ変換する |
| `base` | `ja` | 母語。返答の地の文に使う言語（ISO 639-1 コード） |
| `target` | `en` | 学習言語（ISO 639-1 コード。例: `en` `fr` `de` `zh` `ko` `es` `ru`） |
| `ratio` | `10` | 学習言語に置き換える文の割合（%、0〜100） |
| `level` | `B1` | 学習言語の難しさ（CEFR: `A1`〜`C2`）。語彙と構文をこの水準に収める |
| `register` | `auto` | 丁寧さ。`auto`: 元の文に合わせる / `polite`: 丁寧 / `casual`: くだけた言い方 |
| `listener` | `auto` | 話し相手。`auto` / `superior`: 目上 / `peer`: 対等・友達。敬称や二人称の使い分け（tu/vous、Sie/du など）に使う |
| `speaker` | `unspecified` | 話し手の性別。`male` / `female` / `unspecified`。文法上の性で形が変わる言語にだけ使う。`unspecified` のときは性が出ない言い方を選ぶ |
| `reading` | `off` | 非ラテン文字の学習言語（zh, ru, ar など）で読み方を添えるか。`off` / `on`（ピンイン・翻字を文の後ろに括弧で添える） |
| `anchor` | `40` | ratio がこの値未満のとき、各段落の最初の文を母語のまま残し、学習言語の文を連続させない |
| `answer` | `request` | 答え合わせの出し方。`request`: 頼まれたときだけ / `end`: 毎回の返答の末尾に対応表を付ける |

### 置き換えの単位
- 置き換えは必ず**文まるごと**で行う。文末記号（。！？. ! ? など）で区切られた 1 文を、意味の同じ学習言語の 1 文に差し替える
- 学習言語の文の中に母語を混ぜない。母語の文の中に学習言語の単語を混ぜない（もともと外来語・固有名詞・コードとして書くものは除く）
- 文の一部だけ、単語だけを置き換えることはしない
- 箇条書きは 1 項目を 1 文として扱う

### どの文を置き換えるか
- 返答の文の数 × `ratio`（四捨五入、`ratio` が 0 より大きければ最低 1 文）を置き換える
- 前後の母語から意味が予測できる文を優先する。直前の文の言い換え・理由・結果・補足・感想などが向いている
- `ratio` が `anchor` 未満なら、各段落の最初の文は母語のまま残し、置き換えた文を連続させない
- 置き換える文は返答全体に均等に散らす

### 置き換えないもの
- コードブロック、コマンド、ファイルパス、識別子、エラーメッセージ、URL、数値・設定値
- 見出し、表
- 警告・注意・取り消せない操作の説明など、誤読すると困る文（データ削除、本番環境、セキュリティ、費用に関わるもの）。これらは必ず母語で書く
- ユーザーが母語以外で書いた文や、引用

### 訳し方
- 直訳ではなく、学習言語の母語話者がその場面で自然に書く文にする。母語の語順をなぞらない
- `level` を超える語彙や構文は、同じ意味のより平易な言い方に置き換える
- 丁寧さは `register`、敬称・二人称は `listener`、文法上の性は `speaker` に従う
- 長さは元の文と同じくらいにする。1 文を 2 文に分けたり、情報を足したりしない
- `reading=on` のとき以外は、置き換えた文に訳や注釈を付けない

### 答え合わせ
- `answer=end` なら、返答の末尾に「置き換えた文 → 元の母語の文」の対応表を付ける
- `answer=request` なら、ユーザーが「答え」「訳」と言ったときだけ、直前の返答の対応表を示す
- ユーザーが分からなかった表現を聞いてきたら、母語で短く説明する

### テキスト変換
- ユーザーが「/mix」に続けて文章を貼ったら、その文章自体を上のルールで変換して返す（`mode` に関係なく動く）
- 「/mix target=de ratio=40」のように値が付いていれば、その変換だけその値を使う（以後の既定値は変えない）
- 貼られた文章の言語が `base` と違う場合は、その言語を母語とみなして変換する
- 変換結果だけを返し、前置きや解説は付けない

### 例
`base=ja target=en ratio=20` のとき
元: 昨日の会議は延期になった。クライアントがもう少し時間がほしいと言ってきたからだ。おかげで来週まで準備の余裕ができた。正直に言えば、これは悪い知らせではない。
変換後: 昨日の会議は延期になった。The client asked for a bit more time. おかげで来週まで準備の余裕ができた。正直に言えば、これは悪い知らせではない。

`base=ja target=fr ratio=20 listener=peer` のとき
変換後: 昨日の会議は延期になった。Le client voulait un peu plus de temps. おかげで来週まで準備の余裕ができた。正直に言えば、これは悪い知らせではない。
